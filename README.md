# Фінальний проект для другого модуля Python University від JavaRush

## http-сервер для перегляду та зберігання зображень у вигляді веб-додатку.

Суть проста: користувач заходить на сайт, завантажує фотки чи картинки, а натомість отримує прямі посилання на них.
Ці посилання можна використовувати де завгодно — у соцмережах, блогах або просто надіслати друзям.
   - Завантажувати можна лише файли в популярних форматах (.jpg, .png, .gif).
   - Обмеження розміру файлу: до 5 МБ.
   - Генерує унікальне ім'я для кожного завантажуваного зображення.

### Використано
- **Backend**: Python 3.13 (`http.server`)
- **Web Server**: Nginx
- **Containerization**: Docker & Docker Compose
- **Frontend**: HTML5, CSS3, JavaScript

## Запуск через Docker Compose

### Скрипт що встановить та запустить

#### Linux 

```bash
git clone git@github.com:taibadp/PyUProj2.git
cd PyUProj2
docker compose up --build
```

#### Windows
```powershell.exe
git clone git@github.com:taibadp/PyUProj2.git
cd PyUProj2
docker compose up --build
```

### Ручний запуск вже встановленого (завантаженого)
```bash
docker compose up --build
```

### Робота
В бравзері відкрити
http://localhost:8080

### Режими роботи

*1. Головна сторінка*
- **Маршрут:** `http://localhost:8080`
- Функціональність:
  - Зустрічає користувача вітальним повідомленням та розповідає про сервіс.
  - Містить посилання на основні маршрути:
  - Сторінка завантаження зображень (`/upload`).
  - Каталог завантажених зображень (`/images/`).

*2. Завантаження зображень*

- **Маршрут:** `/upload`
- **Метод:** `POST`
- Функціональність:
   - Приймає файл зображення від користувача через HTTP-запит.
   - Підтримувані формати: `.jpg`, `.png`, `.gif`.
   - Обмеження розміру файлу: до 5 МБ.
   - Генерує унікальне ім'я для кожного завантажуваного зображення.
   - Зберігає зображення в папку `/images` на сервері.
   - Повертає користувачу унікальний ідентифікатор файлу та посилання на зображення.
