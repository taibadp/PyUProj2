# Сервер зображень 2.0 (Image Hosting)

Фінальний проєкт для другого модуля Python University (JavaRush) з підтримкою баз даних PostgreSQL, пагінації та управління контентом.

## 📋 Опис проєкту

Веб-додаток для перегляду, завантаження та зберігання зображень. Користувач може завантажувати картинки (у форматах `.jpg`, `.png`, `.gif` розміром до 5 МБ), після чого метадані зберігаються в базі даних PostgreSQL, а самі файли доступні за прямими посиланнями.

### Основний функціонал версії 2.0:
1. **Завантаження зображень** з перевіркою розміру, формату та валідацією вмісту.
2. **Зберігання метаданих** (назва, оригінальне ім'я, розмір, дата, тип) у **PostgreSQL**.
3. **Каталог зображень (`/images-list`)** з виведенням повної інформації та підтримкою **пагінації** (по 10 елементів на сторінку).
4. **Видалення зображень** (одночасне видалення запису з бази даних та фізичного файлу з диска через маршрут `/delete/<id>`).
5. **Система логування** всіх дій користувача та помилок у файл `app.log`[cite: 1, 21].
6. **Резервне копіювання (бекапи)** бази даних за допомогою вбудованих інструментів PostgreSQL.

## 🛠 Технології

- **Backend:** Python 3.10+ (`http.server`, `psycopg`)[cite: 3, 21, 22]
- **База даних:** PostgreSQL
- **Обробка зображень:** Pillow[cite: 5, 21]
- **Веб-сервер / Проксі:** Nginx[cite: 1, 4]
- **Контейнеризація:** Docker та Docker Compose[cite: 1, 21]
